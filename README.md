# AI Trading System with API

This repository provides a compact reference implementation of an AI-powered
trading assistant. A lightweight HTTP server exposes endpoints that return
trading signals generated by a custom logistic regression model trained on
simple technical indicators. The project demonstrates how to combine data
loading, feature engineering, machine learning, and API layers in a
maintainable structure without third-party dependencies.

## Features

- **Data loading** – Load packaged CSV price data or provide your own.
- **Feature engineering** – Compute moving averages, volatility, and momentum
  features suitable for short-term classification models.
- **Machine learning model** – Custom logistic regression with feature
  scaling predicts the probability of an upward move.
- **Backtesting** – Evaluate strategy performance metrics on the bundled
  dataset.
- **HTTP service** – REST endpoints for health checks, training, prediction,
  and backtesting built on top of the Python standard library.

## Getting started

1. **Run the API**

   ```bash
   python -m app.main
   ```

   The server listens on port 8000 by default and can be adjusted by calling
   `app.main.run(host, port)` from another module.

2. **Use the endpoints**

   - `GET /health` – service status.
   - `POST /train` – retrain the model using optional custom CSV path.
   - `POST /predict` – provide a JSON body with `closes` array to receive the
     next-step signal.
   - `GET /backtest` – view performance metrics.

3. **Run tests**

   ```bash
   pytest
   ```

## Extending the system

- Replace `data/sample_prices.csv` with a larger dataset or integrate live
  market data ingestion.
- Swap the logistic regression for more sophisticated models (e.g., gradient
  boosting, recurrent networks).
- Implement position sizing, risk management rules, and portfolio metrics in
  the `AITradingService`.
